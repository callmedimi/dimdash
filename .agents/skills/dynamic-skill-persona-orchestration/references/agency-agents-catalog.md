# Global Agency-Agents Catalog

Location: `/root/.gemini/config/skills/agency-*`

This document indexes all globally installed agency personas categorized by capability domain.

---

## 1. Architecture, Backend & Systems
- **agency-backend-architect**: Senior backend architect specializing in scalable system design, database architecture, and microservices.
- **agency-software-architect**: System design, domain-driven design, and technical decision-making for large-scale architectures.
- **agency-database-optimizer**: Schema design, query optimization, indexing strategies, PostgreSQL/MySQL tuning.
- **agency-database-reliability-engineer**: High availability, replication, disaster recovery, and database operations.
- **agency-api-platform-engineer**: OpenAPI/gRPC contracts, SDK generation, rate limiting, and API gateways.
- **agency-realtime-collaboration-engineer**: WebSockets, SSE, CRDTs, OT, and offline-first sync engines.
- **agency-rust-refactoring-specialist**: Repository-scale refactoring, memory safety, and Clippy remediation.
- **agency-webassembly-engineer**: Rust/C++/Go to Wasm compilation, runtime boundaries, and optimization.

## 2. Frontend, Mobile & UI/UX Design
- **agency-frontend-developer**: Modern web technologies, component libraries, UI implementation, and client performance.
- **agency-ui-designer**: Visual design systems, component styling, accessible UI creation.
- **agency-ux-architect**: Foundations, structural design, and CSS design tokens.
- **agency-ui-finish-gate-reviewer**: Guardrail against generic UI, ensuring high-fidelity visual standards.
- **agency-desktop-app-engineer**: Electron and Tauri desktop architectures, IPC, and native OS integration.
- **agency-mobile-app-builder**: Native iOS/Android and cross-platform frameworks.
- **agency-mobile-release-engineer**: Code signing, Fastlane pipelines, and App Store/Play Console releases.
- **agency-accessibility-auditor**: WCAG audits, screen reader compliance, and inclusive design.

## 3. DevOps, SRE & Cloud Infrastructure
